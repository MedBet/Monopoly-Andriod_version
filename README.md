A fully functional Monopoly board game for Android devices. Play the classic property trading game against AI opponents.

## ✨ Features

- 🎲 **Classic Monopoly rules** – properties, houses/hotels, jail, Chance/Community Chest cards, auctions, and mortgaging.
- 🤖 **AI opponents** – single-player mode with a configurable number of computer players.
- 🎨 **Multiple Activities** – clear separation of game stages: Start, Main Game, Dice Roll, and End screens.
- 💾 **Persistent game state** – save and resume your game at any time.
- 🔊 **Sound effects** (optional) – toggle on/off in settings.
- 📊 **Statistics tracking** – monitor your wins, total games, and best streaks.

## 🛠️ Tech Stack

- **Language:** Java
- **Minimum SDK:** Android 5.0 (API 21)
- **Target SDK:** Android 14 (API 34)
- **Architecture:** Activities-based with XML layouts
- **IDE:** Android Studio
