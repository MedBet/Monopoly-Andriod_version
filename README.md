A classic Monopoly board game for Android. **Play solo against smart AI opponents** – no friends or internet connection needed. Buy properties, build houses, trade, and try to bankrupt all AI players.

### ✨ Features

- 🤖 **Single‑player only** – you vs. 1–3 AI opponents.
- 🎲 **Full Monopoly rules** – properties, houses/hotels, jail, Chance/Community Chest, auctions, mortgaging.
- 🧠 **Adaptive AI** – difficulty levels (Easy / Medium / Hard).
- 💾 **Save / Load** – continue any game later.
- 🎨 **Clean Material UI** – intuitive interface with clear game state.
- 🔊 **Sound & music** – optional, can be toggled off.
- 📊 **Statistics** – track your wins, total games, and best streaks.

### 🛠 Tech Stack

- **Language:** Java
- **Minimum SDK:** Android 5.0 (API 21)
- **Target SDK:** Android 14 (API 34)
- **Architecture:** Activities + XML layouts
- **IDE:** Android Studio
