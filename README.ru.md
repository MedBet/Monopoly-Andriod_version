# Monopoly – Android (версия с ИИ)

![Android](https://img.shields.io/badge/Android-3DDC84?style=flat&logo=android&logoColor=white)
![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=java&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green

Полнофункциональная версия настольной игры «Монополия» для Android. Играйте один против ИИ-соперников, следуя классическим правилам покупки и торговли недвижимостью.

## ✨ Особенности

- 🎲 **Классические правила «Монополии»** – собственность, дома/отели, тюрьма, карточки «Шанс» и «Общественная казна», аукционы, залог недвижимости.
- 🤖 **Игра против ИИ** – одиночный режим с настраиваемым количеством компьютерных противников.
- 🎨 **Разные экраны (Activity)** – логическое разделение этапов игры: старт, основное поле, бросок кубиков, окончание игры.
- 💾 **Сохранение состояния** – возможность сохранить игру и продолжить позже.
- 🔊 **Звуковые эффекты** (опционально) – отключаются в настройках.
- 📊 **Статистика** – отслеживайте свои победы, общее количество партий и лучшие серии.

## 🛠️ Технологии

- **Язык:** Java
- **Минимальная версия Android:** 5.0 (API 21)
- **Целевая версия Android:** 14 (API 34)
- **Архитектура:** Activities + XML-разметка
- **Среда разработки:** Android Studio
